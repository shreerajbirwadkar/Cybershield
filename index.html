Awareness Topics

Cyber Security Awareness

Understand common cyber threats.

🎣 Phishing

Phishing is a cyber attack where criminals use fake emails, messages or websites to steal sensitive information.

🔐 Password Security

Use long, unique passwords and avoid using the same password on multiple websites.

📱 Mobile Security

Install applications only from trusted sources and keep your mobile operating system updated.

🌐 Safe Browsing

Check website addresses carefully and avoid downloading files from suspicious websites.

💳 Online Scams

Never share OTPs, PINs, passwords or banking information with unknown people.

🔑 Two-Factor Authentication

2FA provides an additional layer of security beyond your password.

Cyber Safety Tips

Simple habits can improve your online security.

🔐 Use Strong Passwords

Create long and unique passwords for important accounts.

🚫 Never Share OTP

Banks and legitimate services do not require you to share OTPs.

📲 Enable 2FA

Use two-factor authentication wherever possible.

🔄 Update Software

Install security updates and patches regularly.

📧 Verify Emails

Check the sender and link before clicking.

💾 Backup Data

Keep important files backed up in a safe location.
